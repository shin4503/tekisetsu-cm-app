# 適切なケアマネジメント手法　基本ケア☀︎疾患別一覧アプリ

日本総研「適切なケアマネジメント手法」の項目一覧を、状態（疾患・期）や利用者の状況から探しやすくした、HTMLファイル1つのアプリです。

**現在は非公開です。日本総研への利用許諾を確認中のため、許諾が得られるまで公開しません。**

## ファイル
- `index.html` … アプリ本体（これ1つで動きます。オフライン可）
- `icon.svg` … アイコン（ハートを両手で包む絵柄）

## できること
1. 状態をえらぶ（基本ケア、脳血管疾患・大腿骨頸部骨折・心疾患のⅠ期／Ⅱ期、認知症、誤嚥性肺炎の予防）
2. 状況で絞る（ひとり暮らし、身寄りがない など20の状況。ふだんは閉じています）
3. 候補にチェックを付けて抜け漏れを確認する
4. チェックにタイトルを付けてストックする（端末のブラウザ内に保存）
5. 項目名を押すと、支援の概要・必要性、主なアセスメント／モニタリング項目、相談すべき専門職、関連する項目、関連する資料を個別に開ける

## 収録内容
- 基本ケア 44項目（令和5年6月版）
- 疾患別ケア 163項目（令和6年12月版）
- 項目名は原本のまま、それ以外の説明は原本を短く要約した表現です。正確な内容は各項目の「原本はこちら」から日本総研の原本で確認してください。
- 「状況で絞る」の結びつきは、ことばの一致で拾った目安です。手引きが定めた対応づけではありません。

## 注意
- 利用者の氏名などの個人情報は入力しないでください。
- 視点を示す道具です。判断はケアマネジャーが行います。
